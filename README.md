## About

A ten-slide presentation on what corporate governance is, why investors price it,
how they apply it in practice, where it falls short, and how India regulates it —
closing with the Satyam Computer Services case of 2009.

It is a single self-contained HTML file. No build step, no dependencies, no
frameworks — open `index.html` in any browser and it runs.

## Interactive parts

- **Slide 2** — click each party to see how governance fails at that point
- **Slide 3** — click a pillar to expand it
- **Slide 4** — switch governance safeguards off and watch the required return
  rise and the company's value fall, live
- **Slide 5** — type in any three years of profit and the mandatory CSR spend
  under Section 135 is calculated instantly
- **Slide 6** — click an approach for its trade-off
- **Slide 8** — click a year on the timeline
- **Slide 9** — click through the Satyam story step by step

## Controls

| Key | Action |
|-----|--------|
| `→` `←` `Space` | Next / previous slide |
| `O` | Slide overview grid |
| `F` | Fullscreen |
| `Home` / `End` | First / last slide |

Clicking the left or right edge of the screen also navigates, and swiping works
on touch devices. Any slide can be linked directly — `#4` opens slide 4.

## Running it locally

Download or clone the repository and open `index.html`. That is all.
